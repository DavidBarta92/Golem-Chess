# Button

A játék meglévő lekerekített gombja: papír kitöltés, 1,5 px tintakeret, `radius-md`.

- Magasság `button-size`, vízszintes belső margó `space-8`, szöveg `button-label`.
- Hover `paper-hover`; lenyomva / nyitva `ink` kitöltés `paper` szöveggel; tiltva `paper-shade` kitöltés, `line-soft` keret, `ink-faint` szöveg.
- Csak ikon: `button-size` négyzet — így néz ki a menü gomb is.
- **Primary** (`ink` kitöltés) nézetenként legfeljebb egyszer, a fő teendőre — pl. „Begyűjtés” a küldetéspanelen. Kicsi méret (40 px) csak panelen belül.
- Felirat: egy-két szó, mondatkezdő nagybetűvel.
