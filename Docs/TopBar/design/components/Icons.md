# Icons

Tintavonalas ikonok 24 px-es rácson, 1,75 px vonallal, kerek végekkel; kitöltés csak jelentést hordozó színből.

- Számlálók (`icon-stat`): érme (`coin` kitöltés), rajzpont — ceruza egy `draw` körben, rang — dupla csúcsív, mint most.
- Menü (`icon-menu`): menü, multiplayer, beállítások, tutorial, kilépés.
- Szalag (`icon-ribbon`): könyv (történet), érme, rajzpont; jelvények: homokóra, pipa.
- Szalagon az ikon egyszínű: kitöltés nélkül, a szalag `on-…` színében.
- Ezek vázlatok: az érme helyére a játék saját érmerajza kerüljön; a többi ikon a játék vonalstílusában újrarajzolható.
